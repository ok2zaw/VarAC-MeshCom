Z uzlu zatím nepřichází žádná data. Zkontrolujte:
  1. v uzlu MeshCom (konzole nebo aplikace): --extudp on a --extudpip {{ local_ip or '<IP-Raspberry-Pi>' }}, poté uzel restartujte (--reboot) a ověřte výpisem --info. Uzel posílá data jen na tuto jedinou adresu – pokud tam zůstala IP jiného počítače (např. s MeshCom klientem), Pi nedostane nic, i když odesílání z Pi funguje,
  2. sériovou konzoli uzlu po startu: má vypsat [EXT]...now sending to IP …. Hláška [EXT] target … refused znamená, že uzel adresu odmítl (broadcast, 0.0.0.0 nebo vlastní IP uzlu); [EXT] no WiFI connection open znamená, že uzel není připojen k Wi-Fi jako klient,
  3. že port nedrží jiný program: sudo ss -lunp | grep {{ cfg.mesh_udp_port }} (má jej mít jen python gateway),
  4. zda datagramy na Pi vůbec dorazí: sudo tcpdump -ni any udp port {{ cfg.mesh_udp_port }},
  5. firewall na Pi, např. sudo ufw allow {{ cfg.mesh_udp_port }}/udp, a izolaci klientů Wi-Fi (AP isolation) v routeru.
